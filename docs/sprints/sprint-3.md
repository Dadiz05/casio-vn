# Sprint 3 - CRUD sản phẩm và upload

## Mục tiêu

- Hoàn thiện module CRUD sản phẩm.
- Thêm upload ảnh sản phẩm có preview và validate.

## Công việc đã thực hiện

- Xây dựng trang Admin Products.
- Cho phép thêm, sửa, xóa và tìm kiếm sản phẩm.
- Bổ sung component UploadImage.
- Kiểm tra định dạng JPG/PNG/WebP và giới hạn file 2MB.
- Kết nối upload vào form thêm/sửa sản phẩm.

## Kết quả

- Admin quản lý được catalog sản phẩm.
- Có thể dùng URL ảnh hoặc upload file ảnh trực tiếp khi tạo sản phẩm.
