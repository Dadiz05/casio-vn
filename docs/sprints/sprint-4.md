# Sprint 4 - CRUD đơn hàng/người dùng, search/filter/pagination

## Mục tiêu

- Hoàn thiện module Orders và Users.
- Bổ sung tìm kiếm, lọc và phân trang cho shop.

## Công việc đã thực hiện

- Tạo Admin Orders với tìm kiếm, lọc trạng thái và cập nhật trạng thái đơn.
- Tạo Admin Users với tìm kiếm, đổi trạng thái và xóa user.
- Cải thiện Shop với filter theo dòng, giá, bộ máy, giới tính và tồn kho.
- Thêm pagination cho danh sách sản phẩm.

## Kết quả

- Đáp ứng đủ 3 module CRUD/lõi: Products, Orders, Users.
- Shop hỗ trợ tốt các thao tác tìm kiếm và lọc sản phẩm.
